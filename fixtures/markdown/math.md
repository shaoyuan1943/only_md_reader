# Math Fixture

Inline math should render in the text flow: $E = mc^2$.

Block math should render as a separate block:

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

A deliberately wide formula should support horizontal scrolling when needed:

$$
\sum_{i=1}^{n} \left(a_i^2 + b_i^2 + c_i^2 + d_i^2 + e_i^2 + f_i^2 + g_i^2 + h_i^2\right)
$$
