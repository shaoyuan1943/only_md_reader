# Tauri 手工验收脚本

用于第一版主流程人工复验。每次发布候选构建前，按顺序执行并记录结果。

## 前置条件

- 使用最新构建产物或 `pnpm tauri dev` 启动的桌面应用。
- 准备 `fixtures/markdown/basic-syntax.md`、`fixtures/markdown/gfm-table-task-list.md`、`fixtures/markdown/relative-image.md` 和一个只读 Markdown 文件。

## 验收步骤

1. 打开文件：从打开文件窗口选择 `.md` 文件，确认新阅读窗口显示正文、大纲和文件路径。
2. 多窗口：连续打开两个不同 Markdown 文件，确认生成两个独立阅读窗口。
3. 重复打开聚焦：在第一个文件窗口滚动到中段，再从打开文件窗口或最近使用列表再次打开同一文件，确认聚焦已有窗口，不创建重复窗口，不重置滚动位置。
4. 设置保存：点击打开文件窗口和阅读窗口的齿轮按钮，确认只出现一个设置窗口；修改主题、字体、字号、行高或正文宽度，关闭并重新打开应用后确认设置仍生效。
5. 阅读位置恢复：滚动到文档中后关闭阅读窗口，再重新打开同一文件，确认恢复到上次阅读位置；若文件内容明显变化，确认回到顶部而不是跳到错误位置。
6. 错误路径：尝试打开不存在文件、非 Markdown 文件、目录路径和编码异常文件，确认用户看到可读错误，应用不白屏。
7. 图片失败：打开包含缺失图片的 Markdown，确认图片位置显示加载失败状态，正文其他内容继续可读。
