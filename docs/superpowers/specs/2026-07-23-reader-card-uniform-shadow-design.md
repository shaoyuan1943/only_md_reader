# 阅读窗口卡片四周均匀阴影设计

## 1. 目标

让阅读窗口的大纲卡片和阅读卡片使用完全相同的阴影，并让每张卡片的上、下、左、右四周都能看到强度均匀的阴影。

本次只调整阴影，不调整卡片或正文布局。

## 2. 已确认约束

- 保持阅读窗口外边距 `--window-card-inset: 18px` 不变。
- 保持大纲卡片宽度 `--reader-outline-width: 336px` 不变。
- 保持两张卡片之间的间距 `--reader-card-gap: 30px` 不变。
- 保持阅读区内部左右 padding `96px` 不变。
- 保持正文最大宽度 `--reader-content-max-width` 的现有行为不变。
- 不增加实体边框，不改变卡片 `22px` 圆角。
- 明亮和暗色主题都必须能辨认四周阴影。

只有在真实可视验证证明现有布局无法显示均匀阴影时，才重新讨论布局调整；不得在本次实现中自行改变卡片宽度或正文宽度。

## 3. 阴影方案

两张卡片共用同一个阴影变量，避免大纲卡片和阅读卡片再次出现强度差异。

阴影由两层无方向偏移的外阴影组成：

```css
--reader-card-shadow:
  0 0 24px -8px color-mix(in srgb, var(--accent) 18%, transparent),
  0 0 8px -2px color-mix(in srgb, var(--accent) 10%, transparent);
```

设计含义：

- `offset-x` 和 `offset-y` 都为 `0`，保证阴影不向任何方向偏移。
- 第一层保留柔和、宽阔的阴影过渡。
- 负扩展值将主要可见阴影控制在现有窗口留白内，减少窗口边缘裁剪和卡片中间阴影叠加。
- 第二层补充贴近卡片边缘的阴影，让四周边界在明亮和暗色主题下都可辨认。
- 删除当前仅作用于顶部的 `inset 0 1px 0` 高光，避免顶部与其他三边不一致。

## 4. 实现范围

仅修改以下内容：

- `src/App.css` 中阅读窗口卡片阴影变量及大纲、阅读卡片的阴影引用。
- 与旧的两级阴影变量直接绑定的前端静态回归测试。
- `tools/reader-ui-qa.*` 中与卡片阴影直接相关的可视断言；仅在现有覆盖不足时补充。
- 完成实现和验证后，同步更新 `docs/implementation-worklist.md` 的对应验证记录。

不修改：

- React 组件结构。
- Rust / Tauri 窗口尺寸和最小尺寸。
- 大纲宽度、阅读卡片宽度、正文宽度、正文 padding、卡片间距和窗口外边距。
- 主题 JSON、设置结构和持久化逻辑。

## 5. 验收标准

1. 大纲卡片和阅读卡片的计算后 `box-shadow` 完全相同。
2. 两张卡片上、下、左、右四周都有可辨认且无方向偏移的阴影。
3. 大纲卡片左侧和阅读卡片右侧不再出现明显缺失阴影的现象。
4. 卡片中间区域不因两层阴影叠加而明显深于外侧。
5. 明亮和暗色主题均通过可视检查。
6. 卡片宽度、正文宽度、窗口外边距和卡片间距与修改前一致。

## 6. 验证

实现后执行：

```powershell
pnpm test
pnpm lint
pnpm format:check
pnpm build
pnpm qa:reader-ui
pnpm tauri build --no-bundle --ci
```

`pnpm qa:reader-ui` 需要至少覆盖：

- 1920×1080 明亮主题。
- 1920×1080 暗色主题。
- 项目规定的最小有效阅读窗口尺寸。
- 两张卡片四边阴影可见性。
- 修改前后卡片和正文几何尺寸一致。
