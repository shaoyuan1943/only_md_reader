# PDF 导出通知无边框设计

## 目标

移除 PDF 导出成功、失败通知卡片的可见边框线，其余视觉和交互保持不变。该调整同时应用于正式 PDF 导出版本和临时强制失败预览版。

## 已确认方案

采用真正移除边框并补偿原 `1px` 边框占位的方案，不使用透明边框伪装无边框。

- `.reader-preview-notification` 从 `1px solid` 改为 `border: 0`。
- 卡片 padding 从 `11px 14px` 改为 `12px 15px`：原来文字位置为 `1px border + padding`，补偿后标题、详情的屏幕位置和卡片总高度不变。
- 关闭按钮从 `top/right: 8px` 改为 `top/right: 9px`：移除边框后仍保持距卡片外缘 `9px` 的原有实际位置。
- 错误通知只保留 `color: var(--button-danger-bg)`，删除错误边框颜色规则。
- 卡片宽度、`14px` 圆角、背景、阴影、字体、两行布局、`28px` 文字右侧避让、省略号、通知栈位置、进入/退出动画全部不变。
- 关闭按钮自身 SVG 中的圆环属于用户指定图标内容，继续保留；本需求只移除通知卡片外框线。

## 验证契约

- 静态测试先锁定通知卡片 `border: 0`、`padding: 12px 15px` 和关闭按钮 `top/right: 9px`，并确认错误规则不再设置 `border-color`。
- PDF QA 在浅色和暗色场景中断言通知边框宽度为 `0px`、样式为 `none`，关闭按钮相对卡片外缘仍为 `9px`。
- 浅色和暗色截图均需人工核对：卡片外框线不可见；文字、关闭按钮、圆角、阴影、宽度和省略号与原方案一致。
- 成功通知 3 秒自动关闭、成功通知手动关闭清理计时器、错误通知不自动关闭、真实坐标点击关闭等既有行为继续通过。
- 正式版与临时强制失败版分别运行固定 PDF/Reader UI QA、测试、lint、格式检查、前端构建和 Tauri 无安装包构建；临时默认 API 继续固定失败且不写 PDF。

## 分支边界

- 正式实现位于 `codex/pdf-export-notification`，继续使用 `createPdfExportApi()`。
- 临时预览位于 `codex/pdf-export-error-preview`，同步相同无边框 CSS/测试，但保留固定失败 `defaultPdfExportApi`。
- 临时分支继续禁止合并到正式分支或 `main`，用户验收完成后删除。
