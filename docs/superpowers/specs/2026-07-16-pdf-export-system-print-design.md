# PDF 导出 V1（系统打印）设计说明

- 日期：2026-07-16
- 状态：用户已确认；待审阅此文档后再进入实现计划
- 范围：MD 极简阅读的 PDF 导出 V1

## 1. 目标

用户从阅读窗口点击导出按钮后，应用使用当前 Markdown 的真实渲染结果和打印专用样式打开系统打印流程；用户在系统窗口中自行选择“另存为 PDF”或等价 PDF 打印机。

本功能优先保证：完整正文、中文可读性、本地图片、表格、代码块、KaTeX 公式和分页不被阅读器滚动容器截断。

## 2. 已确认的产品决策

| 项目 | 决策 |
|---|---|
| 导出方式 | 系统打印流程，用户自行另存为 PDF；不直接写出指定路径文件。 |
| 触发方式 | 只能点击阅读窗口内的导出按钮。 |
| 快捷键 | 不支持；`Ctrl+P` / `Cmd+P` 必须被拦截，不能绕过资源准备流程。 |
| 打印主题 | 固定浅色、高对比打印主题；不忠实导出暗色阅读主题。 |
| 默认纸张 | A4；系统打印窗口仍可让用户选择实际纸张和打印机。 |
| 页眉页脚 | 不做应用自定义页眉、页脚或页码模板。 |
| 文件名 | PDF 正文中不显示 Markdown 文件名。 |
| 导出内容 | 仅 Markdown 正文，不含大纲、卡片外壳、浮动按钮、复制控件、滚动条、文件路径或文件名。 |
| 图片失败 | 保留已有失败占位，允许导出。 |
| 图片超时 | 中止本次导出并提示重试；不能静默导出缺图文档。 |

## 3. UI 合同

### 3.1 导出按钮

- 位置：阅读卡片右下角的操作区，位于现有齿轮设置按钮正上方。
- 尺寸：`32px × 32px`。
- 形状：圆形，半径 `16px`。
- 与设置按钮的垂直间距：`6px`。
- Hover / tooltip 文案：`导出为PDF文档`。
- 无障碍名称：`导出为PDF文档`。
- 导出准备中按钮禁用，并有可访问的“正在准备导出”状态；不得覆盖正文、代码块、公式或表格。

## 4. 技术设计

### 4.1 复用现有渲染管线

```text
Markdown
  -> unified / remark / rehype / KaTeX / Shiki
  -> .markdown-rendered-document
  -> PDF 专用 @media print / @page CSS
  -> document.fonts.ready + 图片状态 + 最终布局帧
  -> window.print()
```

- 不再解析一遍 Markdown。
- 不创建隐藏导出窗口。
- 不新增 Rust command、保存文件权限或原生 WebView PDF 桥接。
- 不改变 Markdown 源文件、阅读位置或用户设置。

### 4.2 导出前就绪条件

调用 `window.print()` 前必须满足：

1. 当前 Markdown 渲染任务已经完成；
2. HTML 已提交到当前阅读窗口 DOM；
3. `document.fonts.ready` 已完成；
4. 全部正文图片已成功加载，或已进入现有失败占位；
5. 至少完成一次最终 `requestAnimationFrame` 布局帧；
6. 没有另一项导出任务正在进行。

图片仍未稳定时，默认最多等待 10 秒；超过时间后结束本次导出准备并提示用户重试。

### 4.3 打印样式合同

- `@page` 默认 A4 和合理页边距。
- 解除 `html`、`body`、`#root` 和阅读滚动容器的固定高度/overflow 限制。
- 隐藏应用 UI，仅使 `.markdown-rendered-document` 进入打印文档流。
- 强制浅色高对比颜色、浅色代码主题和可打印背景。
- 标题、图片、引用、代码块、表格和块级公式需要分页面策略。
- 宽表格、长代码和长公式不能在右侧裁切；单块内容过长时允许自然跨页。

## 5. 非目标

- 直接保存 PDF 至指定路径、静默导出、自动打开 PDF。
- 自定义封面、页码、页眉页脚、书签、目录页和模板系统。
- Pandoc、LaTeX、外置 Chromium、wkhtmltopdf 和 Rust PDF 绘制库。
- macOS 未经实机验证前的跨平台完成宣称。
