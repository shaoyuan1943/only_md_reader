# PDF 自动缩小设置设计说明

- 日期：2026-07-17
- 状态：用户已确认交互与导出语义；等待用户审阅本书面规格
- 范围：PDF 导出初始字号、超宽内容处理模式，以及设置界面入口

## 1. 目标

PDF 导出始终以 `12pt` 正文作为排版起点，同时提供一个持久化设置，让用户选择是否允许超宽内容触发整份 PDF 自动缩小。

该设置不改变阅读窗口字号，也不让 PDF 初始字号跟随阅读器字号。它只决定导出过程中遇到超宽内容时，采用局部换行/适配，还是允许 WebView2 对整份 PDF 做全局缩小。

## 2. 设置界面

设置窗口新增一个持久化开关：

- 名称：`允许自动缩小 PDF 内容`
- 辅助说明：`遇到无法换行的超宽内容时，允许整体缩小页面。不同文档导出的最终字号可能不一致。`
- 默认状态：关闭
- 设置字段：`pdfAllowGlobalScaling: boolean`
- 旧设置文件缺少该字段时：按 `false` 处理

第一步只修改 `docs/ui/settings.html` 设计原型，不接入真实设置存储或 PDF 导出逻辑。原型必须同时展示明亮和暗色主题，并使用用户指定的开关图标路径。

### 2.1 开关图标

- 关闭状态：圆点位于左侧，使用用户提供的关闭 SVG path。
- 开启状态：圆点位于右侧，使用用户提供的开启 SVG path。
- 保留 SVG 的 `viewBox="0 0 1024 1024"` 和 path 几何。
- 图标颜色跟随设置窗口主题文字/控件颜色，不能在暗色主题中固定为 `#222222`。
- 开关必须具有明确的选中状态表达，不能只依靠颜色区分。

## 3. 导出模式

### 3.1 固定字号模式（默认，开关关闭）

- PDF 正文固定从 `12pt` 开始。
- 普通文本自然换行。
- 行内代码优先保持单个词组完整，并允许在相邻代码片段边界换行。
- 单个超长代码串允许内部换行。
- 图片限制到 A4 可打印宽度。
- 表格、块级公式等极端宽内容只在自身范围内换行或缩放。
- 任何单个超宽元素都不能带动整份 PDF 缩小。

### 3.2 允许自动缩小模式（开关开启）

- PDF 正文仍从 `12pt` 开始。
- 普通文本继续使用浏览器的自然换行。
- 不再用固定模式的局部适配规则阻止超宽元素扩张打印布局。
- 图片、表格、公式或不可断行代码造成页面超宽时，允许 WebView2 决定是否整体缩小 PDF。
- 不保证不同 Markdown 文档的最终视觉字号一致。
- 自动缩小由内容宽度触发，与阅读器字号和显示器 DPI 无关。

## 4. 高 DPI 行为

- A4 页面、页边距和字号分别使用物理打印单位 `mm`、`in` 和 `pt`。
- Windows 100%、150%、200% 等显示缩放不应改变 PDF 内部页面尺寸或初始 `12pt` 字号。
- 不把 `devicePixelRatio`、窗口缩放或阅读器视觉缩放写入 PDF 导出参数。
- 不同显示器或 PDF 阅读器在“100%”查看时可能呈现不同屏幕物理大小，但这不等于 PDF 内部字号变化。

## 5. 持久化与兼容

- 新字段沿用现有 ReaderSettings 的前端、Rust、本地 JSON 持久化和窗口广播链路。
- 默认值为 `false`，保证升级后继续使用已经验收的固定字号模式。
- 设置变化只影响之后的 PDF 导出，不修改当前 Markdown、阅读位置或阅读窗口视觉字号。
- 导出开始后锁定本次模式；导出完成或失败后恢复所有临时 DOM 状态。

## 6. 验证标准

### 6.1 UI 原型

- `docs/ui/settings.html` 的明亮和暗色界面均显示该设置。
- 两个主题分别展示可辨识的开关状态，SVG path 与用户提供内容一致。
- 标签、辅助说明和开关在现有设置窗口尺寸内不截断、不溢出。
- 运行 `pnpm qa:screenshots` 并人工检查生成截图。

### 6.2 后续功能实现

- 设置默认关闭，旧配置缺字段时也是关闭。
- 固定模式导出多个宽度差异明显的文档，正文主字号约为 `12pt`，超宽元素不触发全局缩小。
- 自动缩小模式使用相同文档，正文以 `12pt` 起步；只有存在超宽内容时才允许最终字号小于 `12pt`。
- Windows 至少在 100% 和一个高 DPI 缩放档位实机导出同一固定模式样本，比较 A4 页面尺寸、正文主字号和分页结果。
- 运行设置、阅读器、PDF 专项测试及无安装包 release 构建。

## 7. 非目标

- 不增加自定义 PDF 字号输入框。
- 不让 PDF 字号跟随阅读器正文字号。
- 不增加每次导出前的模式选择窗口。
- 不改变 A4、浅色高对比、无页眉页脚和同目录递增文件名等既有 PDF 导出约束。
