# UI 原型说明

本目录用于存放 Markdown 阅读器的 UI 沟通原型。

## 分辨率基准

UI 设计和适配以 `1920x1080` 为基础分辨率。

当前三个独立 HTML 文件都使用 1920x1080 作为原型画布语境，核心窗口在该分辨率下居中显示。后续正式实现时，应以 1920x1080 验证基础布局，再验证更小窗口、高 DPI 缩放和 macOS Retina。

当前原型文件：

- `open-file.html`：打开文件窗口。
- `reader.html`：打开 Markdown 文件后的阅读窗口。
- `settings.html`：点击设置按钮后的设置窗口。
- `styles.css`：三个窗口共用的视觉变量和基础样式。

可直接用浏览器分别打开：

```text
E:\only_md_reader\docs\ui\open-file.html
E:\only_md_reader\docs\ui\reader.html
E:\only_md_reader\docs\ui\settings.html
```

## 当前覆盖的状态

原型拆分为三个独立窗口：

1. 打开文件窗口。
2. 打开 Markdown 文件后的阅读窗口。
3. 点击设置按钮后的设置窗口。

## 已确认的布局规则

- 打开文件窗口居中显示“打开文件”按钮。
- 最近打开文件列表显示在打开按钮下方。
- 最近文件每项分两行：
  - 第一行：文件名。
  - 第二行：路径。
- 实际 UI 不需要虚线框。
- 阅读窗口左侧是大纲视图。
- 大纲以树形结构显示。
- 大纲支持节点折叠。
- 大纲与渲染视图联动，当前节点需要加粗或高亮。
- 右侧是 Markdown 渲染视图。
- 渲染视图永远居中显示。
- 设置按钮放在渲染视图右下角。
- 设置窗口采用左侧设置项、右侧设置内容布局。

## 设计边界

当前原型是低保真布局稿，不代表最终颜色、间距和组件细节。

后续沟通方式：

- 每个窗口单独修改和定稿。
- 不再使用一个 HTML 内切换多个 tab 的方式沟通。
- 三个窗口可共享基础设计语言，但允许各自独立调整布局比例。
- 窗口大小用深色实线框表达，便于直接判断窗口尺寸和比例。

后续正式实现时，需要继续验证：

- Windows 和 macOS 原生窗口外壳下的实际可用空间。
- 大纲很长时的滚动行为。
- 设置按钮是否遮挡宽表格、长公式或长代码块。
- 小窗口尺寸下阅读视图和设置窗口的响应式布局。
