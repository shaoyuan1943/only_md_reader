Pure Reader · Tauri 2 + React

Markdown 阅读器技术方案

本项目是一个面向 Windows 和 macOS 的 Markdown 阅读器。核心目标是 纯阅读优先，一个窗口阅读一个 Markdown 文件，左侧显示大纲， 右侧显示居中的渲染内容。

阅读区正文受最大宽度约束，窗口变宽时只增加两侧留白，不把段落无限拉长。 设置入口固定在阅读视图右下角留白处，不进入正文内容流。

渲染能力

Markdown 管线使用 unified / remark / rehype，并覆盖 GFM、相对路径图片、 标题锚点、大纲同步和安全 HTML。代码块主题默认采用 VS Code Eva Theme 风格。

UI 的第一职责是让长文档可长期阅读，而不是把阅读器做成半吊子的编辑器。

数学公式

块级公式需要支持横向滚动，并在失败时保留原始公式文本。

∫ab f(x) dx = F(b) - F(a)

代码块

function openMarkdown(filePath) {
  return createReaderWindow({
    filePath,
    themeMode: "system"
  });
}
