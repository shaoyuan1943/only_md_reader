Warm Paper 控件颜色补全

阅读视图里的按钮、下拉框、输入框、开关、禁用态、焦点态均已加入 token。

这版仍然保持 Warm Paper 的温润纸感。正文、标题、链接、引用、表格、代码块继续服务于阅读；设置界面控件则使用同一套暖棕色逻辑，不会突然变成后台系统风格。

主按钮使用强调色，次按钮使用低对比暖色块，输入框和下拉框使用接近纸面的浅层 surface。
