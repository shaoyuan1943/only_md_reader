# Markdown 阅读器产品路线图

> 本文件只维护产品级路线图：阶段顺序、功能范围、产品验收口径和暂缓范围。
> 具体实现任务、技术拆分、完成状态、完成时间、验收标准和验证记录统一维护在 `docs/implementation-worklist.md`。
> 技术路线和架构细节以 `docs/technical-architecture.md` 为准。

## 1. 总体原则

先完成稳定、高质量的纯 Markdown 阅读器，再实现会修改源文件的 CriticMarkup 批注功能。

第一版的产品目标很窄：

- 打开 Markdown 文件。
- 在独立窗口中舒适阅读。
- 大纲、公式、代码、表格、图片等技术文档内容能稳定显示。
- 明亮 / 暗色 / 跟随系统模式可用。
- 用户阅读偏好可以保存。
- Windows 和 macOS 上像普通桌面应用一样打开文件。

第一版不追求编辑器能力，不做文件管理器，不做标签页，不做云同步。

## 2. 阶段 1：基础桌面阅读壳

目标：让应用成为一个可以启动、可以打开本地 Markdown 文件的桌面阅读器。

产品功能：

- 启动应用后显示打开文件窗口。
- 从系统默认程序、双击文件或命令行路径进入时，直接显示对应阅读窗口，不先显示打开文件窗口。
- 支持打开 `.md` 和 `.markdown` 文件。
- 打开文件窗口支持拖入 `.md` / `.markdown` 文件。
- 一个 Markdown 文件对应一个独立阅读窗口。
- 支持同时打开多个 Markdown 文件。
- 重复打开同一文件时聚焦已有窗口，不创建重复窗口。
- 阅读窗口包含左侧大纲区域和右侧正文阅读区域。
- 阅读正文居中显示，不随窗口无限拉宽。
- 阅读窗口提供右下角设置入口。

产品验收：

- 用户可以从应用内选择并打开 Markdown 文件。
- 用户可以把 Markdown 文件拖到打开文件窗口中打开。
- 从打开文件窗口打开文件后，打开文件窗口关闭，只保留阅读窗口。
- 用户可以同时阅读多个 Markdown 文件。
- 同一文件不会被重复打开成多个窗口。
- 1920x1080 下窗口布局比例正确，阅读区域不显得拥挤或失衡。
- 设置入口位置清楚，且不遮挡正文。

## 3. 阶段 2：核心 Markdown 阅读

目标：让普通 Markdown 文档可以被可靠阅读。

产品功能：

- 支持 CommonMark 基础语法。
- 支持 GFM 表格。
- 支持 GFM 任务列表。
- 支持删除线。
- 支持自动链接。
- 支持相对路径图片。
- 从标题生成左侧大纲。
- 支持大纲点击跳转。
- 支持正文滚动时同步高亮当前大纲项。
- 支持隐藏 / 显示左侧大纲，让阅读区进入沉浸式阅读状态。
- 支持正文和大纲中的选中文本复制。
- Markdown 解析失败时显示可理解的错误状态。

产品验收：

- 常见 Markdown 文档可以稳定显示。
- 大纲层级符合文档标题结构。
- 点击大纲可以准确跳到对应标题。
- 滚动阅读时大纲当前项能同步变化。
- 用户可以隐藏大纲让正文阅读区扩展，也可以快速恢复大纲。
- 用户可以复制正文或大纲中的选中文本。
- 表格、图片等内容不会把页面布局撑坏。
- 出错时用户能知道是文件或渲染失败，而不是看到空白窗口。

## 4. 阶段 3：技术文档富内容阅读

目标：补齐技术文档常见内容，让阅读器适合长期阅读工程、数学和产品文档。

产品功能：

- 支持行内数学公式。
- 支持块级数学公式。
- 支持代码块语法高亮。
- 支持一键复制完整代码块。
- 默认代码块主题采用 VS Code Eva Theme，明亮模式对应 Eva Light Bold，暗色模式对应 Eva Dark Bold。
- 代码块主题能适配明亮和暗色模式。
- 长代码行可以横向滚动。
- 宽公式可以横向滚动。
- 宽表格可以横向滚动。
- 单个公式、代码块或图片失败时，不影响整篇文档继续阅读。

产品验收：

- 常见数学公式可以正常显示。
- 常见编程语言代码块可以高亮显示。
- 用户可以通过代码块右上角复制按钮复制完整代码块。
- 未识别语言仍能作为纯文本代码块阅读。
- 明亮和暗色模式下代码块都有合适的视觉效果。
- 宽内容不会破坏整体阅读布局。
- 单个富内容块异常时，不导致整个文档白屏。

## 5. 阶段 4：外观、主题与阅读偏好

目标：让阅读体验可长期使用，并能记住用户偏好。

产品功能：

- 支持明亮模式。
- 支持暗色模式。
- 支持跟随系统模式。
- 使用 Warm Paper 作为默认视觉方向。
- 默认使用随应用打包的 Maple Mono NF CN 字体。
- 支持正文字体设置。
- 支持代码字体设置。
- 字体选择器显示随包默认字体和本机可用字体族，避免只提供少量硬编码候选。
- 支持正文字号设置。
- 支持代码字号设置。
- 支持行高设置。
- 支持正文最大宽度设置。
- 支持代码块主题设置。
- 设置可以本地保存，重启后继续生效。
- 阅读窗口默认最大化打开；原生最大化按钮或双击标题栏可在最大化和 `1320x560` 还原态之间切换；用户也可以通过窗口边缘拖曳调整窗口大小，但不能拖小于 `1320x560` 内容区。`1320x560` 下左侧大纲卡片和右侧阅读卡片仍左右并排，右侧阅读卡片宽度不少于 `880px`。
- 每个 Markdown 文件可以恢复上次阅读位置。
- 文件仍在窗口中时再次打开，只聚焦窗口，不重置当前阅读位置。
- 设置只能通过齿轮按钮打开全局单例系统原生设置窗口：打开文件窗口为中央卡片右下角齿轮，阅读窗口为右下角齿轮；设置窗口已存在时重复点击只聚焦已有设置窗口。

产品验收：

- 用户可以切换明亮、暗色、跟随系统模式。
- 主题切换后界面立即更新。
- 未安装 Maple Mono NF CN 的机器上，默认字体仍能正常显示。
- 用户调整字体、字号、行高和正文宽度后，重启应用仍然有效。
- 用户关闭文件再打开时，能回到上次阅读位置。
- 设置文件异常时，应用仍能以默认设置启动。
- 高 DPI、暗色模式、小窗口下没有明显模糊、遮挡或错位。

## 6. 阶段 5：系统集成与打包

目标：让应用像普通桌面阅读器一样安装、启动和打开 Markdown 文件。

产品功能：

- 支持 Windows 打包。
- 支持 macOS 打包。
- 支持注册 `.md` 文件打开方式。
- 支持注册 `.markdown` 文件打开方式。
- 支持双击 Markdown 文件打开。
- 支持命令行传入文件路径打开。
- 支持引导用户设置默认 Markdown 打开程序。
- 所需字体、公式、代码高亮等资源离线可用。
- 应用自身运行资源全部来自包内，不依赖 CDN 或远程资源。

产品验收：

- Windows 安装包可以安装并运行。
- macOS 应用包可以运行。
- 双击 `.md` / `.markdown` 文件可以打开应用并显示文件内容。
- 从命令行传入文件路径可以打开对应文件。
- 离线状态下，默认字体、公式和代码高亮仍可用。
- 离线状态下，应用界面样式、主题、字体、公式和代码高亮都不缺失。
- Windows 缩放比例和 macOS Retina 下界面显示正常。

## 7. 阶段 6：性能、兼容与安全

目标：提高大文档、异常文档和不可信文档下的稳定性。

产品功能：

- 较大 Markdown 文件可以阅读。
- 文件读取失败时显示明确错误。
- 图片加载失败时显示明确状态。
- 只读 Markdown 文件仍可阅读。
- Markdown 内嵌 HTML 不执行脚本。
- 异常内容不会导致整篇文档白屏。
- 基础系统集成可用，但不使用左上角应用菜单、系统菜单或快捷键作为设置入口。

产品验收：

- 较大的 Markdown 文件不会明显卡死应用。
- 文件不存在、权限不足、编码异常时，用户能看到明确提示。
- 不可信 Markdown 不能执行脚本。
- 单个内容块失败不影响其他内容阅读。
- 只读文件可以正常打开和阅读。

## 8. 阶段 7：PDF 导出 V1（原生无界面直出）

目标：在不引入第二套排版引擎的前提下，将当前 Markdown 阅读结果以稳定的浅色 A4 版式直接生成 PDF，不显示任何打印或预览界面。

产品功能：

- 阅读窗口提供显式的圆形“导出 PDF”按钮，位于设置按钮正上方；悬停提示为“导出为PDF文档”。
- 不提供导出快捷键；`Ctrl+P` / `Cmd+P` 不能绕过按钮触发的资源准备流程。
- 导出前等待正文渲染、字体和图片稳定；图片超时则提示重试，不导出不完整内容。
- 导出使用 A4 默认打印版式和浅色高对比主题。
- PDF 仅包含 Markdown 正文，不包含阅读器大纲、浮动按钮、文件名、文件路径、滚动条或其他应用 UI。
- Windows 通过当前 WebView2 的原生 `PrintToPdf` 直接写文件，禁用浏览器页眉页脚与浏览器打印预览；不使用 PDF 打印机。
- 文件保存在 Markdown 同目录、默认同名 `.pdf`；若存在同名文件则递增为 ` (1)`、` (2)`，绝不覆盖。
- 导出成功与失败均以左下角通知反馈：最新通知在最下方，错误最多同时显示三条且只说明原因；通知使用应用背景、圆角、强阴影和左右进出动画，成功 3 秒自动关闭。

明确不做：

- 应用内选择保存路径、覆盖已有 PDF、自动打开 PDF。
- 封面、书签、目录页、自定义页眉页脚和页码模板。
- Pandoc / LaTeX 或独立 PDF 渲染引擎。

产品验收：

- 用户只能点击导出按钮开始导出，过程中不出现浏览器预览、系统打印或保存路径窗口。
- 长文、中文、图片、宽表格、长代码和数学公式均不会被界面滚动容器截断。
- PDF 是浅色高对比打印版，且不包含阅读器外壳 UI。
- Windows 完成实机无界面导出验证；macOS 未实现时只显示明确错误，不回退到打印窗口。

## 9. 阶段 8：CriticMarkup 批注

目标：在纯阅读器稳定之后，实现协作友好的源文件批注。

产品功能：

- 显示已有 CriticMarkup 高亮。
- 显示已有 CriticMarkup 评论。
- 显示新增、删除、替换建议。
- 支持创建高亮评论批注。
- 支持删除批注。
- 支持接受或拒绝新增、删除、替换建议。
- 批注直接写回 Markdown 源文件。
- 阻止会破坏 Markdown 结构的危险选区写回。

明确不做：

- 私有数据库批注。
- sidecar 批注文件。
- 云同步批注。
- 实时协作。
- 复杂锚点恢复。
- 完整 Markdown 正文编辑器。

产品验收：

- 已有 CriticMarkup 能正确显示。
- 用户可以选中文本并添加评论批注。
- 批注写回后，Git diff 能清楚看到源文件变化。
- 其他人拿到同一个 Markdown 文件即可看到批注内容。
- 不允许的选区会被拒绝，不会破坏 Markdown 文件。

## 10. 第一版可用标准

第一版不包含 CriticMarkup 批注。达到以下标准后，才算第一版可用：

- 双击或打开 `.md` / `.markdown` 文件后，可以在独立窗口稳定阅读。
- 大纲正确。
- GFM 内容正确。
- 数学公式正确。
- 代码高亮正确。
- 明亮、暗色、跟随系统模式正确。
- 字体、字号、行高、正文宽度等阅读设置生效并可保存。
- 每个文件能恢复上次阅读位置。
- Windows 和 macOS 打包可运行。
- 高 DPI 下无明显模糊和布局错位。
- 可以通过阅读窗口的显式按钮无界面生成完整 Markdown 正文 PDF。

## 11. 后续暂缓功能

以下功能不进入当前第一版规划：

- Markdown 正文编辑器。
- 标签页。
- 文件树。
- 全文搜索。
- 自定义 PDF 保存位置、覆盖已有 PDF 和自定义 PDF 模板。
- 云同步。
- 账号系统。
- 实时多人协作。
- 插件系统。
- 第一版内实现 CriticMarkup 批注。

这些功能可以后续重新评估，但不应影响当前阅读器主线。
